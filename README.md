# QTE (Minecraft 1.20.1, Forge 47.2.0+)

Quick Time Event в стиле Minecraft для хоррор-карт: пиксельное кольцо времени, клавиша с фасками, шкала как у опыта,
сердцебиение и дрожь при нехватке времени, кровь при провале. Нужен и на сервере, и на клиенте.

## Команды (права оператора, уровень 2)
- `/qte gui` — окно настройки: пресеты, вкладки «Основное / Звук / Анимация / Действия», живой предпросмотр справа,
  подсказки на каждом поле, кнопки «Тест», «Запустить», «Сохранить»
- `/qte start <игроки> <пресет> [force]` — запустить сохранённый пресет (`force` — игнорировать защиту ниже)
- `/qte quick <игроки> <нажатий> <секунд>` — быстрый запуск серии нажатий (остальное из пресета `default`)
- `/qte stop <игроки>` — прервать QTE без команд успеха/провала
- `/qte list`, `/qte delete <пресет>`

## Защита создателя карты
Пока игроки проходят карту, вы летаете в spectator или creative. QTE вас не касается и не может провалиться за вас:
- **Spectator и creative пропускаются по умолчанию.** QTE у них не появляется, команды успеха/провала не выполняются.
  Включить или выключить: `/qte skip spectator <true|false>`, `/qte skip creative <true|false>`, статус: `/qte skip`.
- **Список игнора** (сохраняется в мире, переживает перезапуск): `/qte ignore add @s`, `/qte ignore remove <игроки>`,
  `/qte ignore list`, `/qte ignore clear`. Игрок из списка не видит QTE в любом режиме игры.
- Если QTE уже идёт, а вы перешли в spectator/creative или добавили игрока в игнор, оно тихо отменяется без команд.
- Пропущенному игроку выдаётся тег `qte_skipped` (теги `qte_success` и `qte_fail` снимаются).
- Кнопка «Тест» в редакторе безопасна: только предпросмотр, команды не выполняются.
  Кнопка «Запустить» запускает по-настоящему, в том числе в creative, и команды выполнятся.

## Режимы
- **Серия нажатий** — набрать N нажатий за T секунд (шкала может «утекать»).
- **Удержание** — держать клавишу заданное время; отпустил — шкала падает.
- **Точный момент** — нажать, когда стрелка в зоне; N попаданий, допустимое число промахов.

## Анимации
- Появление: выскок, проявление, выезд, вращение, **глитч**, **подкрадывание**
- При нажатии: пульс, волны, искры, вспышка, **рывок**
- При успехе: взрыв, свечение. При провале: осколки, **кровь**, тряска
- При нехватке времени: сердцебиение, мерцание, дрожь, «призрак» у текста, красная виньетка в такт сердцу

## Для датапаков
По завершении игроку выдаётся тег `qte_success` или `qte_fail`, а команды из пресета выполняются от его имени с правами 2.
Если игрок пропущен защитой, он получает `qte_skipped`.
Пример: `/execute as @a[tag=qte_success] run say Успех!`
